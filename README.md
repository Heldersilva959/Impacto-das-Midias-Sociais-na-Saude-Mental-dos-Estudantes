# 📊 Impacto das Mídias Sociais na Saúde Mental dos Estudantes

Projeto desenvolvido para a disciplina de **Probabilidade e Estatística**, com o objetivo de analisar a relação entre o uso das mídias sociais e indicadores de saúde mental em estudantes utilizando técnicas de análise estatística e visualização de dados.

## 📖 Sobre o projeto

O crescimento do uso das mídias sociais entre estudantes tem levantado discussões sobre seus possíveis impactos na saúde mental, qualidade do sono, desempenho acadêmico e bem-estar.

Este projeto realiza uma análise descritiva de uma base de dados contendo informações de **5.000 estudantes**, permitindo identificar padrões e tendências relacionados ao comportamento digital e seus possíveis efeitos sobre a saúde mental.

> **Observação:** Trata-se de uma análise estatística descritiva. Os resultados indicam associações entre variáveis, mas não estabelecem relações de causa e efeito.

---

## 🎯 Objetivos

- Caracterizar o perfil dos estudantes participantes.
- Identificar as plataformas de mídias sociais mais utilizadas.
- Avaliar o tempo médio diário de uso das redes sociais.
- Analisar a relação entre:
  - Tempo de uso das redes sociais;
  - Horas de estudo;
  - Horas de sono;
  - Atividade física;
  - Nível de estresse;
  - Pontuação de saúde mental.
- Identificar possíveis fatores associados ao bem-estar dos estudantes.

---

## 📂 Base de Dados

A pesquisa utiliza a base pública:

**Student Social Media and Mental Health Impact**

Disponível em:

https://www.kaggle.com/datasets/shivasingh4945/student-social-media-and-mental-health-impact

A base contém aproximadamente **5.000 registros** e **13 variáveis**, incluindo informações demográficas, hábitos de uso das redes sociais e indicadores de saúde mental.

### Variáveis qualitativas

- Gênero
- País
- Nível acadêmico
- Plataforma mais utilizada
- Finalidade principal de uso
- Nível de estresse

### Variáveis quantitativas

- Idade
- Horas médias diárias nas redes sociais
- Número de desbloqueios do celular
- Horas de estudo
- Horas de atividade física
- Horas de sono
- Pontuação de saúde mental
